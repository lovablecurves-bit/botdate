# Contributing

BotDate is a proprietary project. Read [LICENSE](LICENSE) and [OWNERSHIP.md](OWNERSHIP.md) before you open a pull request.

## How to open a pull request

1. Work on a branch (or a fork if you do not have write access).
2. Keep the change focused. Leave product behavior, founder credit, and the ownership terms as they are unless Lisa Clontz has asked for that change in writing.
3. Run `npm test` and `npm run build`. Fix anything those commands report.
4. Open a pull request against `main`. Describe what changed and why.
5. Lisa Clontz (GitHub: **lovablecurves-bit**) approves merges to `main`.

## Pull requests do not grant ownership

A pull request does not grant ownership, equity, a revenue share, or trademark rights. Write access is code access only. Lisa Clontz retains at least 80% of equity and ownership unless she signs a different written agreement. Any equity grant requires a separate written agreement from Lisa. It is never implied by a pull request, a commit, or repository permissions.

## Keep the founder credit intact

The product is created by Lisa Clontz (Lovable Curves). Do not remove or rewrite that credit in the README, LICENSE, OWNERSHIP.md, or the in-app credit line. Contributors may be acknowledged by GitHub handle only.
